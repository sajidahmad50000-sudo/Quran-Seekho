# Quran Seekho

Quran Seekho is a Flutter Android learning/reading project.

## Project

The current release package is kept under `QuranSeekho-v3.4/`.

## Build

GitHub Actions is configured to prepare a Flutter Android build. The release package still needs the complete Flutter source tree to be committed before an APK can be produced from CI.

## Attribution

The Quran text attribution/license information is included in `QuranSeekho-v3.4/LICENSES.md`. Tanzil requires clear source attribution and a link to tanzil.net when its text is used in an application.
