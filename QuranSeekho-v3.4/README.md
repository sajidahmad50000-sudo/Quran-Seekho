# Quran Seekho v3.4

Flutter Android Quran reading app project package.

Included release package features:
- 114 Surahs / bundled Uthmani Quran text
- Search and reading
- Bookmarks
- Resume reading
- Progress tracking and reset
- Menu navigation
- Daily Duas and TTS
- Offline audio download/playback flow
- Reading Practice speech recognition
- Settings, Privacy and About
